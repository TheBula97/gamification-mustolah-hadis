# 🎣 Fishing for Hadith

**Fishing for Hadith** ialah sebuah game pembelajaran interaktif berasaskan HTML untuk membantu pelajar mengulang kaji ilmu **مُصْطَلَحُ الْحَدِيثِ** secara lebih menyeronokkan melalui konsep memancing ikan.

Game ini dibina sebagai bahan bantu mengajar bagi tajuk-tajuk dalam **الْمَنْظُومَةُ الْبَيْقُونِيَّةُ** dan kitab **التَّقْرِيرَاتُ السَّنِيَّةُ عَلَى حَلِّ أَلْفَاظِ الْمَنْظُومَةِ الْبَيْقُونِيَّةِ بِالتَّرْجَمَةِ الْمَلَايُوِيَّةِ**.

---

## 🎯 Tujuan Projek

Projek ini dibangunkan untuk:

- Membantu pelajar memahami istilah-istilah asas dalam ilmu **مُصْطَلَحُ الْحَدِيثِ**.
- Menjadikan ulang kaji lebih menarik melalui unsur gamifikasi.
- Menggalakkan pelajar menjawab soalan Arab bertasykil secara aktif.
- Membantu guru menggunakan bahan digital dalam PdP, ulang kaji, kuiz, atau aktiviti kelas.

---

## 🕹️ Konsep Game

Pemain akan menjalankan aktiviti memancing. Setiap tangkapan ikan akan dikaitkan dengan soalan berkaitan ilmu hadis.

Jika pemain menjawab soalan dengan betul, pemain akan mendapat ganjaran seperti:

- 🪙 Coins
- 🎣 Bait
- 🐟 Koleksi ikan
- ⭐ Rekod pencapaian sesi

Game ini direka supaya pelajar belajar sambil bermain, bukan sekadar menjawab soalan secara biasa.

---

## ✨ Ciri-ciri Utama

- Dibina dalam satu fail HTML.
- Boleh dijalankan terus melalui browser.
- Sesuai untuk komputer, tablet dan telefon.
- Soalan dalam bahasa Arab bertasykil.
- Pilihan jawapan dalam bahasa Arab bertasykil.
- Penjelasan jawapan dalam Bahasa Melayu.
- Menggunakan tajuk-tajuk ilmu **مُصْطَلَحُ الْحَدِيثِ**.
- Mempunyai pilihan topik.
- Mempunyai sistem sesi permainan.
- Mempunyai timer, coins, bait dan koleksi ikan.
- Sesuai untuk digunakan sebagai aktiviti pengukuhan dalam kelas.
